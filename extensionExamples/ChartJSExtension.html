This example illustrates an extension that provides a custom output extension using ChartJS. 

<matte-ace call="..."  barchart>
    ...
</matte-ace>
If a function named barchart_matte is available, it is called to activate the extension. int[] naturals(int n) { int[] a = new int[n]; for(int i = 0; i < n; i++) a[i] = i + 1; return a; }
